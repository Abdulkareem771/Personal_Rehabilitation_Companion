# Maintenance Programs

Maintenance programs preserve capacity after a rehabilitation phase is complete. They use fewer sessions, stable exercise selections, and clear rules for when to return to a higher-support phase.

## Available Programs

- [Shoulder Maintenance](./shoulder-maintenance.md)

## Maintenance Rules

- Keep 1-3 exposures per week.
- Preserve movement quality before increasing load.
- Return to the relevant rehabilitation phase after a flare, new injury, or repeated instability symptoms.
- Reassess every 4-8 weeks.
