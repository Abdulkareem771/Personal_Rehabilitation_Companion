# Voice Cues

Voice cues are short spoken prompts used during guided sessions.

## Naming

```text
exercise-id.voice-cue.topic.v001.mp3
```

## Standards

- One cue per file unless the app later supports cue bundles.
- Calm, neutral delivery.
- No background music.
- Consistent loudness across a cue set.
- Script documented in `../../metadata/`.

## Examples

```text
band-external-rotation.voice-cue.elbow-position.v001.mp3
wall-slide.voice-cue.rib-position.v001.mp3
```
