# Countdowns

Countdown sounds support timed holds, rest periods, and session transitions.

## Naming

```text
countdown.duration.style.v001.mp3
transition.purpose.style.v001.mp3
```

## Examples

```text
countdown.10s.soft.v001.mp3
countdown.30s.soft.v001.mp3
transition.next-exercise.soft.v001.mp3
```

## Standards

- Non-startling.
- Short decay.
- No spoken instruction unless specifically designed as a voice cue.
- Consistent volume across the countdown set.
