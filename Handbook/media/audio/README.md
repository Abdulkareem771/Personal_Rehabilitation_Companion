# Audio

Audio assets support guided sessions, timing, and accessibility.

## Subfolders

- [Voice Cues](./voice-cues/README.md)
- [Countdowns](./countdowns/README.md)

## General Rules

- Keep voice cues short and specific.
- Avoid cues that conflict with exercise markdown files.
- Keep countdown sounds gentle and non-startling.
- Document scripts before recording.
