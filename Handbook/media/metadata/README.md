# Media Metadata

This folder stores templates for documenting assets before and after production.

Metadata files are useful when:

- An exercise needs media but the files do not exist yet.
- A video has multiple camera angles or versions.
- A coaching video needs clinical review.
- An external reference is being used temporarily.
- Audio cues need exact wording and timing.

## Templates

- [Exercise Media Template](./exercise-media-template.md)
- [YouTube Reference Template](./youtube-reference-template.md)
- [Audio Cue Template](./audio-cue-template.md)

## Suggested Metadata File Naming

```text
exercise-id.media.md
exercise-id.youtube.md
exercise-id.audio.md
```

Examples:

```text
band-external-rotation.media.md
wall-slide.youtube.md
side-plank.audio.md
```
