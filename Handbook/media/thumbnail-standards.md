# Thumbnail Standards

Thumbnails are compact previews for grids, search results, and exercise lists.

## Requirements

| Standard | Requirement |
| --- | --- |
| Format | `.webp` |
| Aspect ratio | 1:1 square by default |
| Minimum size | 512 x 512 px |
| Text | No embedded text |
| Subject | Exercise identity must be readable at small sizes |
| Background | Simple and consistent within a media batch |

## Composition

- Center the movement subject.
- Keep key equipment visible.
- Use more negative space than poster images.
- Avoid tiny full-body framing when the exercise is joint-specific.
- Avoid extreme close-ups that remove exercise context.

## Naming

```text
exercise-id.thumb.variant.v001.webp
```

Example:

```text
serratus-punch.thumb.side.v001.webp
```

## App Usage

Thumbnails should be safe for:

- Exercise cards.
- Search results.
- Recently used exercise rows.
- Program previews.
