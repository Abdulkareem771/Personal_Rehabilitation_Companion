# Poster Standards

Poster images are the still frames shown before a video loads or plays.

## Requirements

| Standard | Requirement |
| --- | --- |
| Format | `.webp` primary, `.jpg` fallback only if needed |
| Aspect ratio | Match the paired video |
| Content | Clear start or midpoint position |
| Text | No embedded instructional text |
| Cropping | Working joint, equipment, and posture visible |
| Contrast | Subject clearly separated from background |

## Poster Selection

Choose a frame that answers: "What exercise is this?" before playback starts.

Prefer:

- A stable midpoint of the movement.
- Clear equipment placement.
- Neutral facial expression and natural posture.
- No motion blur.

Avoid:

- End-range positions that look unsafe without context.
- Cropped hands, feet, bands, or anchor points.
- Busy backgrounds.
- Frames where the shoulder, spine, or target joint is hidden.

## Naming

```text
exercise-id.poster.variant.v001.webp
```

Example:

```text
wall-slide.poster.front.v001.webp
```
