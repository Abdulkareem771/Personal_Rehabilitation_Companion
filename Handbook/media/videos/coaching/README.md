# Coaching Videos

Store longer instructional videos here.

## Purpose

Coaching videos explain context that does not fit inside a silent loop:

- Setup details.
- Common mistakes.
- Progression or regression choices.
- Safety decisions.
- Clinical reasoning.

## Naming

```text
exercise-id.coaching.topic.v001.mp4
```

Examples:

```text
wall-slide.coaching.common-mistakes.v001.mp4
side-plank.coaching.regression.v001.mp4
```

## Requirements

- Captions before publication.
- Clinical review before publication.
- Metadata record before publication.
