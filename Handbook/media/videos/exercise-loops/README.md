# Exercise Loop Videos

Store silent looping exercise demonstrations here.

## Purpose

These files provide quick visual confirmation of the movement inside exercise screens.

## Naming

```text
exercise-id.loop.variant.v001.mp4
```

## Required Pairings

Each approved loop should eventually have:

- A poster image in `../../images/posters/`.
- A thumbnail in `../../images/thumbnails/`.
- A metadata record in `../../metadata/`.

## Publication

After approval, link the final loop path from the related exercise markdown `videoLoop` field.
