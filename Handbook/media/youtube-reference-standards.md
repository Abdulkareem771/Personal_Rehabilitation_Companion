# YouTube Reference Standards

YouTube links may be used as external references while native media is planned or produced. They are not the clinical source of truth.

## Acceptance Criteria

A YouTube reference must:

- Demonstrate the same exercise or a clearly labeled variation.
- Come from a reputable clinical, educational, or coaching source.
- Avoid contradictory safety cues.
- Avoid promotional content as the primary instructional value.
- Be reviewed before linking from an exercise file.

## Documentation Requirements

Each reference should record:

- Exercise ID.
- URL.
- Channel or creator.
- Access date.
- Purpose of the reference.
- What it demonstrates well.
- What the app should avoid copying.
- Review status.

Use [youtube-reference-template.md](./metadata/youtube-reference-template.md).

## Replacement Rule

When native media is approved, keep the YouTube reference only if it adds value beyond the native asset.
