# Infographics

Infographics explain clinical concepts, program flow, or educational summaries.

## Naming

```text
topic.infographic.variant.v001.webp
```

Examples:

```text
shoulder-instability-phase-map.infographic.default.v001.webp
posture-micro-breaks.infographic.default.v001.webp
```

## Standards

- Use simple labels.
- Avoid replacing exercise instructions.
- Keep clinical claims consistent with handbook guidance.
- Record source references when an infographic includes evidence-based claims.
