# Images

Image assets support video playback, navigation, and education.

## Subfolders

- [Posters](./posters/README.md)
- [Thumbnails](./thumbnails/README.md)
- [Infographics](./infographics/README.md)

## General Rules

- Use `.webp` for app-facing images unless a future platform requires another format.
- Do not embed instructional text in posters or thumbnails.
- Keep filenames aligned with the related exercise ID.
