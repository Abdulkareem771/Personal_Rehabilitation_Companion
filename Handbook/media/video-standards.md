# Video Standards

## Exercise Loop Videos

Exercise loop videos are short, silent demonstrations for in-app playback.

| Standard | Requirement |
| --- | --- |
| Format | `.mp4` primary, `.webm` optional future variant |
| Duration | 6-15 seconds |
| Audio | None |
| Loop | First and final frame should connect cleanly |
| Framing | Full body part and equipment visible throughout |
| Background | Clean, uncluttered, high contrast |
| Camera | Stable, no zooms or pans |
| Lighting | Even, no harsh shadows over the working joint |
| Speed | Natural exercise speed, not artificially rushed |

## Coaching Videos

Coaching videos explain setup, execution, common mistakes, or progression logic.

| Standard | Requirement |
| --- | --- |
| Format | `.mp4` |
| Duration | 30-180 seconds |
| Audio | Clear speech, no background music by default |
| Captions | Required before publication |
| Structure | Setup, key cue, common mistake, safety note |
| Review | Clinical review required before linking |

## Required Views

Use the fewest views needed to understand the movement.

- **Front:** symmetrical posture, bands, rows, pull-aparts.
- **Side:** trunk position, pressing/punching, thoracic mobility.
- **Three-quarter:** shoulder blade movement and whole-body context.

## Clinical Review Checklist

- Demonstrates the intended exercise, not a variation.
- Shows controlled start and finish positions.
- Avoids visible compensations unless the file is a mistake example.
- Matches the related exercise markdown safety level.
- Does not introduce cues that conflict with the exercise file.

## File Placement

- Exercise loops: `videos/exercise-loops/`
- Coaching videos: `videos/coaching/`
