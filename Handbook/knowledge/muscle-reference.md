# Muscle Reference

This reference provides standard muscle and muscle-group language for exercise metadata and search.

## Metadata Principles

- Use primary muscles for the main intended training target.
- Use secondary muscles for meaningful support or stabilization roles.
- Avoid listing every muscle involved in a movement.
- Prefer consistent group names unless a specific muscle is clinically important.

## Shoulder And Scapula

| Muscle Or Group | Common Role |
| --- | --- |
| Rotator cuff | Centers and controls the humeral head during shoulder movement. |
| Supraspinatus | Supports abduction and humeral head control. |
| Infraspinatus | Supports external rotation and posterior cuff control. |
| Teres minor | Supports external rotation and shoulder stability. |
| Subscapularis | Supports internal rotation and anterior shoulder control. |
| Serratus anterior | Supports scapular protraction and upward rotation. |
| Lower trapezius | Supports scapular depression, posterior tilt, and upward rotation. |
| Middle trapezius | Supports scapular retraction and control. |
| Rhomboids | Support scapular retraction. |
| Latissimus dorsi | Supports pulling and shoulder extension patterns. |
| Deltoid | Supports shoulder elevation and arm positioning. |

## Trunk

| Muscle Or Group | Common Role |
| --- | --- |
| Abdominal wall | Supports trunk stiffness and pressure control. |
| Obliques | Support rotation control and side-bending control. |
| Erector spinae | Support spinal extension and posture. |
| Deep trunk stabilizers | Support low-load positional control and breathing coordination. |

## Hip And Lower Body

| Muscle Or Group | Common Role |
| --- | --- |
| Gluteus maximus | Supports hip extension and lower-body power. |
| Gluteus medius | Supports pelvic control and hip abduction. |
| Quadriceps | Support knee extension and squat patterns. |
| Hamstrings | Support hip extension and knee flexion. |
| Calf complex | Supports ankle control, gait, and propulsion. |
