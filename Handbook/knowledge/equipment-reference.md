# Equipment Reference

This reference standardizes equipment names for exercise metadata, program planning, filtering, and future app search.

## Naming Rules

- Use simple, consistent names.
- Prefer generic equipment names over brands.
- Record optional equipment separately from required equipment.
- Keep equipment labels stable so saved programs and search filters do not break.

## Common Equipment

| Equipment | Standard Label | Notes |
| --- | --- | --- |
| Resistance band | `resistance-band` | Includes loop or long bands unless a specific type matters. |
| Cable machine | `cable-machine` | Use when pulley height or line of pull matters. |
| Dumbbell | `dumbbell` | Single or paired dumbbells. |
| Kettlebell | `kettlebell` | Use only when shape or grip changes the task. |
| Bench | `bench` | Flat, incline, or support bench. Specify angle in exercise notes if needed. |
| Wall | `wall` | Used for support, feedback, or positioning. |
| Chair | `chair` | Stable chair for seated or supported work. |
| Mat | `mat` | Comfort and floor work. |
| Foam roller | `foam-roller` | Mobility, support, or positional feedback. |
| Pull-up bar | `pull-up-bar` | Hanging or pulling support. |
| Bodyweight | `bodyweight` | No external equipment. |

## Equipment Complexity

Use equipment complexity to help apps sort exercises:

- **None:** Bodyweight or environmental support only.
- **Simple:** Band, wall, mat, chair, foam roller.
- **Moderate:** Dumbbell, kettlebell, bench.
- **Gym:** Cable machine, machines, racks, heavy external loading.

## Safety Considerations

- Equipment should not create joint apprehension or uncontrolled resistance.
- Bands should be checked for wear before use.
- Anchor points must be stable when bands or cables are used.
- Gym equipment should allow controlled setup and exit.
