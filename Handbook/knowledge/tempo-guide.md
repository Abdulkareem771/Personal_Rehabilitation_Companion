# Tempo Guide

Tempo describes the speed and timing of each repetition.

Consistent tempo improves dosing, motor control, and exercise comparison over time.

## Four-Number Tempo

Tempo is commonly written as four numbers:

```text
eccentric - pause - concentric - pause
```

Example:

```text
2-1-2-0
```

Meaning:

- 2 seconds lowering or lengthening.
- 1 second pause.
- 2 seconds lifting or shortening.
- 0 second pause before the next repetition.

## Holds

For isometrics and static positions, prescribe time directly.

Examples:

- `10 second hold`
- `20-30 second hold`
- `3 x 30 seconds`

## Rehabilitation Tempo Principles

- Slower tempo can improve control but increases time under tension.
- Faster tempo should usually wait until symptoms and control are stable.
- Pauses can reduce momentum and reveal compensation.
- Tempo should be simple enough to follow during exercise.

## Metadata Guidance

Use the `tempo` field for the default prescription. If the exercise is a hold, use plain-language timing instead of a four-number code.
