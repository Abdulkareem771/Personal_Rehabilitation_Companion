# Flare-Up Management

A flare-up is a temporary increase in symptoms above baseline.

The goal is to reduce irritability, preserve confidence, and return to the appropriate program level.

## First 24-48 Hours

Use a lower-irritability plan:

- Stop provocative strengthening.
- Use comfortable mobility if it settles symptoms.
- Keep daily activity tolerable.
- Avoid testing the painful movement repeatedly.
- Record likely triggers.

## Return Step

When symptoms settle toward baseline:

1. Restart with the last well-tolerated regression.
2. Use fewer sets than usual.
3. Keep range comfortable.
4. Check the next-day response.
5. Progress only after two stable sessions.

## Do Not Chase Lost Progress

After a flare, do not immediately return to the previous top load or volume.

Rebuild using symptom response and movement quality.

## Clinical Review Triggers

Seek review when:

- Symptoms do not settle over several days.
- Resting pain increases.
- Night pain is new or worsening.
- Instability signs appear.
- Neurological symptoms occur.
- Daily function declines.
