# Regression Rules

Regression is a planned reduction in difficulty. It keeps training productive when symptoms, fatigue, or control do not support the current task.

Regression is not failure.

## Regress When

Regress if any are present:

- Pain reaches 3-4/10 and does not settle with cueing.
- Form changes across the set.
- The person compensates with neck, trunk, or momentum.
- Apprehension appears.
- Symptoms remain elevated the next day.
- Recovery between sessions is poor.

## Regression Options

Choose the smallest useful change:

- Reduce resistance.
- Reduce range.
- Reduce reps.
- Reduce sets.
- Increase rest.
- Slow the movement.
- Use a supported position.
- Return to an isometric.
- Switch to mobility or motor-control work.

## Regression Priority

Use this order for most exercises:

1. Improve setup.
2. Reduce resistance.
3. Reduce range.
4. Reduce volume.
5. Change position or support.
6. Return to an earlier phase.

## Return To Progression

Return to the previous level only after:

- Symptoms are back to baseline.
- The regressed version is completed with good quality.
- The next-day response is stable.
