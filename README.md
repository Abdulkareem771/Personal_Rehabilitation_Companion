# Shoulder Recovery

Personal Rehabilitation & Fitness Companion built as an installable offline-first PWA.

## What is included

- React + TypeScript + Vite app scaffold
- GitHub Pages compatible base path
- PWA manifest and service worker
- Mobile-first dashboard, workout tracker, exercise library, progress, diary, nutrition, and doctor timeline
- LocalStorage persistence for checklist, workout completion, and pain diary entries
- Rehabilitation-specific exercise safety badges and "Why this exercise?" explanations

## Run locally

Install Node.js first, then run:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repo includes a GitHub Actions workflow for GitHub Pages. Push to `main`, then enable Pages from GitHub Actions in the repository settings.

## Medical note

This app is a tracking and education companion. It does not replace medical advice from a physician, physiotherapist, neurologist, or surgeon.
